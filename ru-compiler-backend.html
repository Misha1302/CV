Инженер compiler backend/codegen с профессиональным опытом LLVM 22 в МЦСТ. Публичная backend-линия началась раньше: Visk генерировал и исполнял native x86-64 в 2023 году, Wist4 в 2024-м реализовал AST→IR→x64 с stack frames, вызовами, памятью и floating-point. Современный backend добавляет SSA/CFG, liveness/interference, register allocation/spills, phi lowering и differential execution.

2022: Компиляторы / VM · 2023: CIL + native x86-64 · 2024–2025: AST / IR / backends → toolchain · 2026 →: Профессионально: LLVM + static analysis

Проекты

x86-64 Compiler Backend & Register Allocation

Проверка SSA/CFG → анализ живости и интерференции → register allocation/spills → phi lowering → генерация SysV x86-64.

Verifier раскладки + сравнение native execution с эталонным интерпретатором; актуальный CI проекта зелёный; отдельная публичная линия native-codegen начинается с Visk (2023) и Wist4 (2024).

LLVM Interprocedural Global IV Optimization

LLVM 22 pass локализует поддерживаемые глобальные переменные, изменяющиеся как индукционные, после межпроцедурного анализа эффектов, аффинной эволюции и отдельной проверки условий применимости; APInt моделирует арифметику фиксированной разрядности.

29 позитивных и негативных регрессионных сценариев: LLVM Verifier, структурные ожидания, идемпотентность и сравнение наблюдаемого поведения до/после преобразования.

UniversalToolchain

Разрешение зависимостей и конфликтов, выбор реализаций, порядок проходов и типизированные маршруты артефактов до исполнения.
