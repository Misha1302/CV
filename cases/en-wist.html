UniversalToolchain

Independently owned language contributions must compose into one compiler/runtime pipeline without hidden registration-order dependencies or a second resolver at runtime.

GitHub
01

Problem

Independently owned language contributions must compose into one compiler/runtime pipeline without hidden registration-order dependencies or a second resolver at runtime.

02

Constraints

Independent package versions, multiple backends, determinism, and compatibility.

03

Solution

Typed artifact contracts; dependency/conflict and capability/provider resolution; deterministic pass ordering and artifact routes compiled into an immutable LanguagePlan before execution.

04

Outcome

The plan is fixed before execution and runtime materializes selected components without resolving dependencies again; the canonical test contract currently records 1,306 passing tests.

05

Verification

Canonical test gate, clean-consumer projects, interpreter/CIL parity, deterministic manifests and replayable failures.

06

My ownership

Architecture, core contracts, runtime, SSA, verification strategy, and public documentation.
