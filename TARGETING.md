# Targeting guide — compiler/program-analysis refresh

## Primary profiles

1. `Compiler & Program Analysis Engineer — LLVM · C++ · Static Analysis` — primary for compiler, LLVM, static/program-analysis, compiler-backend, and adjacent code-intelligence roles.
2. `Software Engineer — Architecture & Platforms` — broader architecture/platform roles spanning typed contracts, state/recovery, and compiler/runtime systems.
3. `.NET Backend / Platform Engineer — State & Reliability` — backend/platform roles where payments, idempotency, recovery, migrations, and release correctness dominate.

## Secondary profiles

- `C++ / LLVM Systems` — low-level/backend compiler, systems, performance, and HFT-adjacent applications.
- `Quantitative Research / Research Software Engineering` — only when algorithmic experimentation is central.

Lead with the compiler/program-analysis profile unless the vacancy clearly rewards another evidence ordering. The profiles share facts and differ only in role-specific evidence priority and vocabulary.
