Projects

x86-64 Compiler Backend & Register Allocation

Built a backend for restricted i64 IR: SSA/CFG, liveness, linear-scan and seeded simulated-annealing allocation, spills, phi lowering and SysV x86-64 emission. An independent verifier rejects register/stack-slot conflicts; phi lowering handles parallel-copy cycles.

Native execution runs in a separate process and is compared with an IR interpreter. Passed 42/42 local debug tests, cargo fmt and strict Clippy on commit dd0693c; local release tests were blocked by disk quota during compilation.

LLVM Interprocedural Global IV Optimization

An LLVM pass analyzes interprocedural effects and affine evolution of selected integer-global accesses, then checks legality and conservatively rewrites IR.

Passed 29/29 regression cases on LLVM 22.1.8, including unsupported cases where the transformation is rejected. This is not an LLVM target backend.

UniversalToolchain / Wist2

Developing modular infrastructure with Bytecode/AIR, interpreter and CIL backends. LanguagePlan records selected execution routes; tests check interpreter/CIL parity for supported behavior.

The repository manifest records 1,324 expected passing tests, not a fresh full-suite run during this CV audit.
