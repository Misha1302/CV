C++23 · LLVM 22 · interprocedural analysis · optimization

LLVM Interprocedural Global IV Optimization

The pass must recognize affine evolution of global IVs across calls and transform IR only when correctness conditions are established.

Architecture case study ↗GitHub ↗
  • ProblemThe pass must recognize affine evolution of global IVs across calls and transform IR only when correctness conditions are established.
  • SolutionAn LLVM 22 pass promotes selected integer-global accesses within loops. Effect analysis and a separate PromotionLegality gate precede IR rewriting.
  • ResultPassed 29/29 positive and conservative-rejection regression scenarios on pinned LLVM 22.1.8.
C17 · program analysis · memory dependence

PS-form Memory Dependence Analyzer

Problem: The task is to conservatively determine whether two parametric memory accesses can overlap without enumerating large value domains.

Solution: A GNU C17 analyzer for overlapping memory accesses across distinct loop iterations, combining exact counting for supported affine cases with modular/GCD checks and bounded fallback.

Result: Unresolved cases return conservative maybe. Built as an MCST technical-selection task, not a production dependence-analysis system.

Architecture case study ↗GitHub ↗
Rust · compiler backend · register allocation · SysV x86-64

x86-64 Compiler Backend & Register Allocation

Problem: The goal is to go from IR to executable x86-64 and verify that register allocation preserves semantics.

Solution: An experimental Rust backend for restricted IR with SSA/CFG, liveness, register allocation, spills, phi lowering and SysV x86-64 code generation.

Result: An independent verifier checks register/stack assignments; native results are compared against a reference IR interpreter.
