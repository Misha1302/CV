C++23 · LLVM 22 · interprocedural analysis · optimization

LLVM Interprocedural Global IV Optimization

The pass must recognize affine evolution of global IVs across calls and transform IR only when correctness conditions are established.

Architecture case study ↗GitHub ↗
  • ProblemThe pass must recognize affine evolution of global IVs across calls and transform IR only when correctness conditions are established.
  • SolutionAPInt affine b + k·x evolution, transitive function/module effects, loop/dominator/must-execute reasoning, and a separate conservative legality phase that rejects unsupported CFG/calls.
  • ResultA conservative LLVM 22 prototype/MVP with an actual IR transform; 29 of 29 positive/negative regression cases pass at a fixed revision and cover verifier validity, idempotence, and before/after execution.
Rust · compiler backend · register allocation · SysV x86-64

x86-64 Compiler Backend & Register Allocation

Problem: The goal is to go from IR to executable x86-64 and verify that register allocation preserves semantics.

Solution: SSA-like IR with CFG/SSA validation, liveness/interference, register allocation with an independent assignment verifier, phi lowering, and SysV x86-64 code generation.

Result: A reference interpreter and differential execution check generated-code semantics; the allocator assignment contract is verified independently.

Architecture case study ↗GitHub ↗
C17 · program analysis · memory dependence

PS-form Memory Dependence Analyzer

Problem: The task is to conservatively determine whether two parametric memory accesses can overlap without enumerating large value domains.

Solution: Counts iteration pairs exactly for supported affine address differences; modular/GCD conditions prove selected disjointness cases, while unresolved symbolic inputs remain maybe.

Result: Exact affine iteration-pair counting and modular/GCD disjointness proofs; yes/no cross-checked with a small-domain oracle and metamorphic tests, unresolved cases remain maybe.
