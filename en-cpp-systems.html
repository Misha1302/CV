PS-form Memory Dependence Analyzer

The task is to conservatively determine whether two parametric memory accesses can overlap without enumerating large value domains.

  • ProblemThe task is to conservatively determine whether two parametric memory accesses can overlap without enumerating large value domains.
  • SolutionNormalization, interval constraints, modular reasoning, gcd conditions, plus an exact oracle for small domains and metamorphic checks.
  • ResultConservative yes/no/maybe results checked by an independent exact oracle on small domains, randomized/metamorphic tests, and reproducible counterexamples.
Rust · SSA/CFG · register allocation · SysV x86-64

x86-64 Codegen & Register Allocation Lab

Problem: The goal is to go from IR to executable x86-64 and verify that register allocation preserves semantics.

Solution: SSA-like IR with CFG/SSA validation, liveness/interference, register allocation with an independent assignment verifier, phi lowering, and SysV x86-64 code generation.

Result: A reference interpreter and differential execution check generated-code semantics; the allocator assignment contract is verified independently.

Architecture case study ↗GitHub ↗
.NET · compiler/language infrastructure · deterministic composition

UniversalToolchain

Problem: Independently owned language contributions must compose into one compiler/runtime pipeline without hidden registration-order dependencies or a second resolver at runtime.

Solution: Typed artifact contracts; dependency/conflict and capability/provider resolution; deterministic pass ordering and artifact routes compiled into an immutable LanguagePlan before execution.

Result: LanguageRuntime validates and materializes the exact planned package/component graph without re-planning; plan-determinism/exact-binding checks, ownership guards, and interpreter/CIL parity protect the contract.

Architecture case study ↗GitHub ↗
Compiler testing · configuration plans

PlanFuzz

Problem: Program behavior depends not only on input but also on packages, routes, backends, and optimizations; conventional fuzzing misses that dimension.

Solution: A language-neutral core, typed observations, seven oracle families, fresh-process replay, exact fingerprints, and deterministic program/plan reducers.

Result: Reproducible artifacts and explicit separation of confirmed, unstable, inconclusive, and infrastructure outcomes.
