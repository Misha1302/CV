## Инженерные проекты

**[LLVM Interprocedural Global IV Optimization](https://github.com/Misha1302/LLVM-interprocedural-global-IV-optimization/tree/0d759dcf3af7a5652432eb0fea5b9ca27ec88f74)**

LLVM 22 pass локализует поддерживаемые обращения к целочисленным глобальным переменным в циклах. Анализ эффектов и отдельная PromotionLegality предшествуют IR-преобразованию. На зафиксированном LLVM 22.1.8 пройдены 29/29 регрессионных сценариев с положительными и консервативно отклонёнными преобразованиями.

**[PS-form Memory Dependence Analyzer](https://github.com/Misha1302/ps_form_analizer/tree/758001fdadba56b4f2bd7601464bd6fe0cd2b388)**

GNU C17-анализатор пересечений памяти между разными итерациями. Точный подсчёт для поддерживаемых аффинных случаев, модульные/НОД-проверки, ограниченный перебор. В неразрешённых случаях возвращает консервативное maybe; проект выполнен как техническое задание отбора МЦСТ, не промышленный анализатор.

**[x86-64 Compiler Backend & Register Allocation](https://github.com/Misha1302/x86-64-codegen-ra-playground)**

На Rust реализован экспериментальный backend для ограниченного IR: SSA/CFG, liveness, register allocation, spills, phi lowering и SysV x86-64. Независимый verifier проверяет назначения регистров/stack slots, а результаты native-кода сравниваются с эталонным IR-интерпретатором.
