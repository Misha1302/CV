C++23 · LLVM 22 · межпроцедурный анализ · оптимизация

LLVM Interprocedural Global IV Optimization

LLVM 22 pass для локализации поддерживаемых integer globals внутри циклов. Он анализирует аффинную эволюцию на APInt и транзитивные эффекты вызовов; IR меняется только после отдельной legality-проверки.

29/29 regression cases в CI покрывают успешные преобразования и отказ на неподдерживаемом IR, LLVM Verifier, повторный запуск pass и сравнение поведения до/после для исполняемых случаев.

.NET · compiler / language infrastructure

UniversalToolchain

Модульная инфраструктура для language/compiler pipelines: зависимости, providers, порядок pass-ов и маршруты артефактов разрешаются до запуска и фиксируются в LanguagePlan.

Runtime исполняет уже выбранный план без второго resolver. Канонический test contract сейчас фиксирует 1 306 успешных тестов; отдельно проверяются binding и согласованность interpreter/CIL.

C# · Roslyn · статический анализ

DerefAfterNullAnalyzer

Roslyn ControlFlowGraph с forward fixed-point data flow: null-состояния передаются по рёбрам CFG и объединяются в join points.

Поддерживаются ветвления, циклы и back edges; successors перерабатываются до стабилизации состояния.
