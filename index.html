C++23 · LLVM 22 · interprocedural analysis · optimization

LLVM Interprocedural Global IV Optimization

Проблема: Нужно доказуемо распознавать affine evolution глобальных IV между функциями и выполнять IR transformation только при достаточных условиях корректности.

Решение: Affine b + k·x на APInt, transitive function/module effects, loop/dominator/must-execute reasoning и отдельная conservative legality-фаза с отказом на unsupported CFG/calls.

Результат: Консервативный LLVM 22 prototype/MVP с реальным IR transform; 29 positive/negative regression cases проверяют verifier validity, idempotence и before/after execution.

C# · Roslyn · static analysis · data-flow

DerefAfterNullAnalyzer

Проблема: Нужно находить потенциально небезопасное разыменование после возможного null с учётом ветвлений, циклов и слияния control-flow.

Решение: Roslyn ControlFlowGraph и forward fixed-point data-flow analysis: состояния Unknown/MaybeNull/NotNull передаются между basic blocks и объединяются на join points.

Результат: Диагностика потенциально небезопасных dereference paths поверх реального CFG, включая повторную обработку successors до стабилизации состояния.

.NET · compiler/language infrastructure · deterministic composition

UniversalToolchain

Проблема: Независимо развиваемые language contributions должны собираться в один compiler/runtime pipeline без скрытой зависимости от registration order и без второго resolver в runtime.

Решение: Модули языка разрешают зависимости и конфликты, выбирают реализации требуемых возможностей и runtime-компонентов, получают детерминированный порядок contributions и типизированные маршруты артефактов до создания runtime.

Результат: Текущий exact test manifest: 1 324/1 324. В frozen-corpus verifier experiment режим B2 обнаружил 32/32 primary и 10/10 challenge operators при 0/100 false positives на valid controls; отдельно проверены 4 post-freeze holdouts.
