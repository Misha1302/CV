.NET · языковая платформа · runtime

Rust · IR · register allocation · x86-64

x86-64 Codegen & Register Allocation Lab

Allocator возвращает общий Assignment, а отдельный verifier проверяет completeness, допустимые registers, spills и live-interval conflicts до codegen

Generated x86-64 поведение сравнивается с reference interpreter; ошибки allocation и emitter локализуются раздельно

C17 · анализ программ · зависимости памяти

PS-form Memory Dependence Analyzer

Portfolio solver сочетает дешёвые доказательства, exact affine reasoning, bounded exhaustive search и witness search; недоказанные случаи остаются unknown/maybe

Малые области проверяются независимым exact oracle, дополнительно используются randomized и metamorphic tests

Тестирование компиляторов · конфигурационные планы

PlanFuzz

Экспериментальный fuzzer типизирует outcomes, сохраняет fingerprints, перепроверяет failure в свежем процессе и минимизирует программу/конфигурацию

Подтверждённые сбои сохраняют воспроизводимый минимальный пример; flaky/infrastructure outcomes не маскируются под compiler bugs
