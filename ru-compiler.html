Архитектура языковых платформ, IR и проверяемые маршруты исполнения.

2024 — сейчас

UniversalToolchain / Wist2 — создатель и основной разработчик

Typed language-authoring SDK · compiler/runtime platform · .NET

  • Спроектировал типизированный SDK, собирающий язык из независимо поставляемых packages: artifact contracts, capabilities/conflicts, детерминированные conversion routes и порядок passes.
  • Реализовал exact manifest binding, schema-v5 lock identity, fail-closed runtime policies и точный выбор backend executor по contribution, backend и input contract.
  • Развиваю callable-first SSA: структурное ядро отделено от descriptor-driven semantics; folding разрешён только для trusted, pure и deterministic callables.
  • Canonical gate от 25.07.2026: 1 459/1 459 тестов, 0 падений, 0 предупреждений и ошибок сборки; проверены 9 packages и clean consumers.

02 · Избранные проекты

Языковая платформа, configuration-aware testing и program analysis.

Проекты показывают разные слои compiler engineering: композицию языков, проверку конфигураций, анализ зависимостей и backend/codegen.

.NET · typed language SDK · compiler/runtime

UniversalToolchain / Wist2

Платформа для типизированной композиции языков и сред исполнения. Wist — публичный facade для проверки ограниченных формул и компиляции одобренных выражений в typed delegates.

GitHub ↗Документация ↗
  • Language plans: typed artifacts, cross-package routes, deterministic passes и exact backend executor.
  • Runtime: per-session ownership, coordinated disposal, policy gates и manifest-backed package identity.
  • SSA: callable descriptors с effects, determinism, trust и capability-checked lowering.
  • Продуктовый слой: Validate/Evaluate/Compile APIs, structured diagnostics и interpreter/CIL parity.
Compiler testing · research tooling

PlanFuzz

Language-neutral configuration-aware differential testing для программ, language-plan variants, backend и optimization routes.

  • Семь oracle families, typed observations и строгое разделение clean/confirmed/flaky/inconclusive/infrastructure.
  • Fresh-process replay, exact fingerprints и воспроизводимые evidence artifacts.
  • Детерминированное program/plan reduction с повторным подтверждением исходного fingerprint.
C17 · program analysis

PS-form Memory Dependence Analyzer

Консервативный анализ параметрических обращений к памяти: 1-е место среди 49 решений и 104/104 тестов.

  • Нормализация, диапазоны, сравнения по модулю и НОД.
  • Точный oracle для малых областей и метаморфные проверки.
  • Воспроизводимые WA/TL cases.
GitHub ↗
Rust · x86-64 backend

Codegen & Register Allocation Lab

SSA-подобная IR, liveness/live intervals, linear scan и генерация x86-64 через iced-x86.

  • Сравнение IR-интерпретатора и сгенерированного кода.
  • Изолированный runner с resource limits.
  • Метрики spills, loads/stores и code size.
