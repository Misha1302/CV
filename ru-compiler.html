C# · Roslyn · static analysis · data-flow

DerefAfterNullAnalyzer

Roslyn ControlFlowGraph + forward fixed-point data-flow: Unknown/MaybeNull/NotNull состояния передаются между basic blocks и объединяются на join points.

Анализ повторно обходит successors до стабилизации и выдаёт diagnostics для потенциально небезопасных dereference paths.

Подробнее ↗GitHub ↗
.NET · modular compiler/runtime framework

UniversalToolchain

Модульный .NET compiler/runtime framework с typed intermediate artifacts, детерминированным LanguagePlan, pass ordering и exact backend routing.

Language composition отделена от runtime execution; архитектурные контракты закреплены executable verification/tests.

x86-64 Codegen & Register Allocation Lab
