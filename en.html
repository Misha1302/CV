.NET backend · payments · subscriptions · recovery

VpnMediator

Problem: Payment, subscription, and actual access can diverge after duplicate webhooks, timeouts, or process restarts.

Solution: Explicit access and payment states, idempotent operations, audit trails, background reconciliation, migrations, and verifiable recovery paths.

Result: A production service with controlled state transitions, backup/restore, health gates, and safe rollback; the public case study excludes secrets and user data.

Architecture case study ↗
C17 · program analysis · memory dependence

PS-form Memory Dependence Analyzer

Problem: The task is to conservatively determine whether two parametric memory accesses can overlap without enumerating large value domains.

Solution: Normalization, interval constraints, modular reasoning, gcd conditions, plus an exact oracle for small domains and metamorphic checks.

Result: Ranked 1st of 49 with 104/104 tests, with reproducible wrong-answer and time-limit counterexamples.

Architecture case study ↗GitHub ↗
Rust · IR · register allocation · x86-64

x86-64 Codegen & Register Allocation Lab

Problem: The goal is to go from IR to executable x86-64 and verify that register allocation preserves semantics.

Solution: SSA-like IR, live-interval analysis, linear scan, iced-x86, isolated execution, and differential parity with an IR interpreter.

Result: A measurable pipeline with spill/reload metrics, code size, and reproducible result comparison.
