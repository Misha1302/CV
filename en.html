Projects

UniversalToolchain / Wist2

Developing modular language infrastructure. LanguageCompiler resolves dependencies and conflicts and builds an immutable LanguagePlan. A verifier checks typed artifact routes, backend ownership, contribution order and the canonical plan hash; runtime does not repeat semantic decisions.

The pipeline includes frontend → Bytecode → AIR → optimizers → interpreter/CIL. Experimental PlanFuzz supports isolated replay and counterexample reduction but is not complete. The repository manifest records 1,324 expected test passes.

LLVM Interprocedural Global IV Optimization

An experimental LLVM pass promotes selected integer-global accesses in loops. Interprocedural effect analysis and legality checks are separated from IR rewriting.

Passed 29/29 regression scenarios on LLVM 22.1.8, including structural checks, idempotence and conservative rejection cases.

x86-64 Compiler Backend & Register Allocation

Built an experimental backend for a restricted IR: SSA/CFG, liveness, register allocation, spills, phi lowering and SysV x86-64 code generation.

An independent verifier checks register and stack-slot assignments; native execution results are compared against a reference IR interpreter.
